# Configuration des Agents locaux du Hub

Ce fichier déclare les agents spécialistes disponibles au sein de l'IDE Antigravity pour le projet **Hub_Alex**.

## Agents Disponibles

### 1. Coordinateur (`.agents/rules/coordinator.md`)
* **Mission** : Point d'entrée unique de l'utilisateur dans l'IDE. Il analyse les demandes globales, gère la TODO-list locale et oriente les actions vers les projets ou délègue à l'Agent Développeur.

### 2. Développeur (`.agents/rules/developer.md`)
* **Mission** : Spécialiste technique du Hub. Il aide à écrire le code en Python/FastAPI, à configurer n8n, à gérer Docker et à concevoir les agents autonomes du backend.
